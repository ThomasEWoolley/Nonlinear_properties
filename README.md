# Repository for "Bespoke Turing patterns with specific nonlinear properties"

This repository contains all computational codes and models associated with the paper **"Bespoke Turing patterns with specific nonlinear properties"**, authored by Thomas E. Woolley. The study introduces a minimal Turing system with just four parameters, enabling any state to become Turing unstable within specified parameter regions. These codes support the theoretical and numerical analyses presented in the paper.

## Contents of the Repository

- **MATLAB Files:** Scripts for:
  - Numerical simulations of Turing patterns.
  - extracting bifurcation diagrams to explore stability regions.
  - Visualisation of reaction-diffusion dynamics.

- **COMSOL Files:** Models for:
  - Simulating reaction-diffusion systems in complex geometries.
  - Verifying the robustness of Turing patterns under varying conditions.

- **Maple Files:** Symbolic computations for:
  - Deriving theoretical conditions for Turing instabilities.
  - Analysing parameter bifurcations.
